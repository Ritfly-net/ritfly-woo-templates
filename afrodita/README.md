# Afrodita — Template visual base

Prototipo estático aprobado como base visual para la futura tienda WooCommerce de Afrodita.

## Alcance

Este directorio conserva únicamente la referencia de diseño y comportamiento aprobada:

- pre-header promocional
- header integrado al hero
- carrusel hero
- franja de beneficios
- categorías populares
- lencería destacada
- grid de productos
- consoladores destacados
- cuestionario / finder (solo teaser visual)
- footer

## Archivos

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

## Uso local

Desde la raíz del repositorio:

```bash
python3 -m http.server 8080
```

Abrir:

```text
http://localhost:8080/afrodita/
```

## Nota

Este prototipo no es el tema WooCommerce final. Se conservará como referencia visual e historial mientras el tema real se desarrolla por separado.
